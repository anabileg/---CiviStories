# ---CiviStories
مشروع توعوي يسلط الضوء على أخطار سوء استخدام السوشيال ميديا وتأثيراتها المدمرة على المجتمع: الطلاق، القطيعة الأسرية، النزاعات، وحتى فقدان الأرواح في حالات متطرفة. An awareness project highlighting the dangers of social media misuse and its devastating societal impacts: divorce, family estrangement, conflicts, and in extreme cases, loss of life.
